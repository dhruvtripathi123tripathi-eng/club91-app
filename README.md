# Club91 GitHub Cloud Build

This package includes a GitHub Actions workflow that builds the Android APK in GitHub's cloud, so Android Studio/AndroidIDE is not required on your phone.

## Phone-only steps

1. Create a GitHub account and a new repository.
2. Upload ALL files/folders from this project to the repository.
3. Open the repository's **Actions** tab.
4. Select **Build APK**.
5. Tap **Run workflow**.
6. Wait for the workflow to finish.
7. Open the completed workflow run and download the **Club91-debug-apk** artifact.
8. Extract the downloaded artifact and install the APK.

The project contains no real-money betting, deposits, withdrawals, or payouts.
